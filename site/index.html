Native Claude Code subagents

A fleet of specialist agents that runs on any provider

AgentFleet installs 19 native Claude Code subagents ("lanes"), each named for a role — plan, implement, review, test — never a model. Point it at your Claude subscription, an Anthropic API key, or any Anthropic-compatible gateway, and every lane gets the best-fit model automatically.

Why AgentFleet

A team of specialists, not one all-powerful agent

Most standard AI tools act as a single, all-powerful agent that can easily make accidental changes and break your software. AgentFleet innovates by replacing this risky setup with a highly structured team of specialized AI assistants.

Just like a real engineering agency, our AI planners are restricted to reading and strategizing, while separate AI coders and testers handle the actual execution. By strictly limiting what each AI is allowed to touch, planning and review can never edit your code, and changes happen only in the lanes built to make them. This brings true enterprise-grade safety and organization to AI development, letting your team build faster with far less risk of breaking things.

11 lanes read, search, and plan

Planning, review, security review, diagnosis, research, exploration, and triage lanes get no Bash, Edit, or Write tools. The doctor fails any read-only lane that has them.

8 lanes make the changes

Implementation, tests, UI, and docs lanes edit code. No lane has the tool to spawn nested agents, and writable lanes are instructed never to commit, push, or deploy: the main agent integrates and owns every outward-facing action.

Features

Built to survive a provider change

Every design decision in AgentFleet exists so that switching providers, or switching models within one provider, never means rewriting your workflow.

Any provider

Works with your Claude subscription, an Anthropic API key, or any Anthropic-compatible gateway whose models are discovered from GET /v1/models.

Role-named lanes

Lane names describe a role — fleet-implement, fleet-review — never a model, so names and workflows survive provider changes.

Capability tiers

Every discovered model gets a tier — cheap, fast, balanced, deep — and each lane is ranked against live models by tier, with automatic fallbacks.

One-command switching

agentfleet use <profile> switches providers without reinstalling. Lanes keep their names; only the models behind them change.

Safe installs

Backups before every apply, one-command rollback, idempotent re-runs, and no overwriting of files it doesn't own.

Privacy-safe routing log

The routing hook logs the lane, reason, timestamp, and character count — never prompt text — to a mode-0600 file that purges itself.

One-line install, automatic updates

A single command downloads a checksum-verified release into your home directory. After that, new releases in the same major version install themselves in the background. No root or admin rights, ever.

How it works

From one command to a ranked fleet

Install

One command downloads a checksum-verified release and runs the installer entirely under your home directory.

The wizard picks a provider

Claude subscription, Anthropic API key, or a custom gateway with live model discovery — on first install only.

Lanes are ranked by tier

At startup, every live model is matched against each lane's required capability tier, with the next-best models kept as fallbacks.

Claude Code delegates

The main agent routes each task to the matching lane by role. Restart after a provider switch and the same lane names still apply.

Providers & profiles

Switch providers without reinstalling

Profiles save the current setup before switching, so switching back restores it exactly. Restart Claude Code after switching.

agentfleet profiles          # list saved profiles (* = active)
agentfleet use native        # switch to your Claude login
agentfleet use <name>        # switch to a saved gateway profile
agentfleet save <name>       # name the current setup

Gateway tokens are stored at ~/.claude/agentfleet/secrets/<name>.token (mode 0600). Switching to native removes gateway environment overrides and maps lanes back to the opus/sonnet/haiku aliases.

Safety & privacy

Nothing changes without a backup

Backups before every apply

All managed files are copied to a mode-0700 snapshot under ~/.claude/backups/claude-agents-config/ before any write.

Rollback

agentfleet rollback restores the newest backup (agentfleet rollback --backup DIR restores a named one). The backup is kept until you remove it.

Idempotent & non-destructive

Repeated installs produce the same configuration. Uninstall removes only files and hook entries this bundle owns.

No accidental overwrites

Existing files without the bundle's ownership marker are never overwritten without --force-owned.

Credential safety

The scanner checks for credential-shaped literals. The gateway token is the only secret normally needed.

Privacy-safe routing log

Only a no-match entry keeps a redacted, max-160-character excerpt. Text is purged after 14 days, entries after 90.

FAQ

Frequently asked questions

Does it work with my Claude subscription?

Yes. It's the default provider: the wizard's first choice uses Claude Code's own login, and lanes map to the opus, sonnet, and haiku aliases.

What does "any provider" actually mean?

An Anthropic API key, or any Anthropic-compatible gateway whose models are discovered from GET /v1/models. Catalogs report context size but not price or speed, which is why explicit tier labels exist.

Can I pin a lane to a specific model?

Yes: claude-fleet-setup --prefer fleet-implement=my-model-id. Clear a pin with claude-fleet-setup --prefer fleet-implement=. A lane with an explicit preferred list respects your order.

How do I roll back or uninstall?

agentfleet rollback restores the newest backup. agentfleet uninstall removes only the files and hook entries this bundle owns and restores earlier settings.

Where do my own Claude Code instructions go?

In ~/.claude/rules/*.md. Claude Code loads those every session and AgentFleet never touches them, because AgentFleet manages and rewrites ~/.claude/CLAUDE.md itself.

Does updating re-run the setup wizard?

No. Updates never run the wizard — they keep your installed profile. Only a fresh interactive install, or an explicit --wizard flag, prompts you.

What happens when I switch providers?

Switching first saves the current setup, so switching back restores it exactly. Lane names never change — only the models behind them do. Restart Claude Code after switching.

What's new

Latest release

v2.0.5 September 24, 2026

Any number of provider profiles: add and remove gateways without reinstalling, and give each profile its own settings.

  • New agentfleet add NAME --gateway-url URL and agentfleet remove NAME add and remove gateway profiles without reinstalling.
  • Each profile keeps its own provider policy, model pins, exclusions, and tier labels, instead of sharing one policy across every profile.
  • Gateway tokens are handled more safely: no redirect leaks, a digest instead of plaintext in the install journal, and no live token sent to a new URL during a dry run.
  • agentfleet update (including automatic updates) now succeeds after agentfleet use native.
  • Uninstall keeps the API-key mask for a gateway you switched to and restores a pre-install gateway exactly.
